# Hadi Khan · Portfolio

Personal site for Hadi Khan, Senior Node.js Backend Engineer. Built with React, Tailwind CSS and Framer Motion, hosted on GitHub Pages.

**Live:** https://hadikhanhk786.github.io/hadi-portfolio

## Editing content

All text (summary, metrics, case studies, experience, skills) lives in [`src/data/profile.js`](src/data/profile.js). The downloadable resume is `public/Hadi_Khan_Resume.pdf`.

## Develop

```bash
npm install
npm start
```

## Deploy

```bash
npm run build
npm run deploy   # publishes build/ to the gh-pages branch
```
